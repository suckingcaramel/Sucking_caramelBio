Маленький вайбкод био, как будто бы ez bio

Музыка загружается из `tracks.txt`, путь задаётся в `config.js` через `tracksFile`. Каждая песня занимает строку в формате `номер|url|название`. Номера — уникальные положительные целые числа; символ `|` внутри URL и названия не используется. Сайт открывайте через HTTP/HTTPS, например Live Server, чтобы TXT загружался.

При открытии выбирается первая песня по номеру, без автоматического воспроизведения. Кнопки переключают песни по кругу. После окончания песни автоматически играет следующая. Название берётся из TXT. Плеер использует браузерный `<audio>` для прямых ссылок на MP3, M4A и другие поддерживаемые браузером аудиоформаты.

Регулятор громкости расположен рядом с кнопкой звука, без чисел и процентов; при ширине окна 520 px и меньше он скрывается. При нуле значок показывает выключенный звук. Кнопка обнуляет громкость, повторное нажатие восстанавливает прежнее значение.

Кнопка перемешивания справа симметрична кнопке звука слева. Она белая по умолчанию и салатовая при включении. В этом режиме ручное переключение и окончание песни выбирают случайный существующий номер в пределах `shuffleMaxTrackNumber` из `config.js`, исключая текущую песню, если есть другой подходящий трек. Изначально лимит — 2, над строкой настройки есть комментарий.

Если TXT не загрузился, некорректен или песня недоступна, плеер использует `assets/music/The_perfect_pair_Beabadoobee.mp3` с названием `The perfect pair - beabadoobee`. Остальные песни доступны при ошибке отдельного трека. При ошибке запасного MP3 показывается сообщение без повторных попыток по кругу. При публикации включите `tracks.txt` и запасной MP3.
