# Страница «Автор»

## Пользовательский курсор

Положите анимированный Windows-курсор в `assets/cursor/cursor.ani`. Путь задаётся в `config.js` через `cursor`; пустая строка отключает замену. Подключённый `cursor.js` читает кадры CUR/ICO внутри ANI, их порядок, длительность и точки нажатия CUR. Курсор действует на странице, включая кнопки и ссылки. При отсутствии файла остаётся обычный курсор. При уменьшенной анимации показывается один кадр.

Открывайте сайт через HTTP/HTTPS: чтение ANI через fetch не работает при обычном открытии HTML как `file://`. Кадры рекомендуется делать размером 32×32; ограничения размера и отображения курсоров зависят от браузера. При публикации включите `cursor.js` и папку `assets`.

Откройте `dist/index.html` в браузере или разместите содержимое `dist` на статическом хостинге. Никаких зависимостей и сборки не требуется.

- `dist/styles.css` — все стили, мобильная версия, затемнение кнопок и скруглённые подсказки.
- `dist/config.js` — имя, описание, URL фона, URL музыки, ссылки и пути к иконкам.
- `dist/script.js` — общий 3D-параллакс трёх блоков и работа плеера.
- `assets/icons/` — локальные иконки.
- `assets/icons/avatar.png` — локальный аватар.
- `assets/music/` — музыкальные файлы; пути задаются в `config.js` через `tracks`.
- `assets/cursor/cursor.ani` — анимированный курсор.
- `dist/discord-avatar.js` — загрузка актуального аватара Discord через Lanyard.

## Автоматический аватар Discord

1. Вступите в Discord-сервер Lanyard: https://discord.gg/lanyard. Это сторонний публичный сервис: после вступления Discord-присутствие, активности и данные профиля доступны через его API. На этой странице используется только аватар.
2. В Discord откройте «Настройки пользователя → Расширенные → Режим разработчика». Нажмите правой кнопкой на свой профиль и выберите «Копировать ID пользователя».
3. В `dist/config.js` укажите `discordAvatar.userId` строкой, например `userId: 'ВАШ_ЧИСЛОВОЙ_ID'`. Это ID, а не ник. Не вводите токен или пароль.
4. Если аватар анимированный, можно изменить `format: 'png'` на `format: 'gif'`.

Аватар загружается при открытии страницы и обновляется раз в пять минут, пока вкладка видима. Задержка обновления зависит также от Lanyard. При ошибке или тайм-ауте используется путь из `avatar`. Оставьте `userId: ''`, чтобы использовать только локальную картинку.

Документация сервиса: https://github.com/Phineas/lanyard#quicklinks. Без вступления в сервер загрузка для вашего ID не гарантируется.

Фон загружается напрямую по URL. Для изображения или GIF задайте `background.type: 'image'`; для MP4/WebM — `'video'`. Видео воспроизводится без звука, по кругу. Используйте прямые HTTPS-ссылки на медиафайлы, а не страницы сервисов. При недоступности фона остаётся однотонный фон.

Музыка включается кнопкой воспроизведения: браузеры ограничивают автоматический запуск аудио. Доступны пауза, перемотка и выключение звука. Добавьте несколько объектов в `tracks`, чтобы переключать песни; с одним треком кнопки возвращают к его началу. По умолчанию используются демонстрационные внешние URL Unsplash и SoundHelix; замените их своими. Ссылки соцсетей пока ведут на главные страницы сервисов.

Все три блока находятся внутри `main.profile` и наклоняются вместе. На сенсорных устройствах наклон отключён. Настройка `maxTilt` задаёт угол. При системном предпочтении уменьшенной анимации параллакс отключается, видео останавливается.

Подсказки появляются при наведении мыши и при фокусе с клавиатуры. Имена приложений заданы в `links[].name`.
